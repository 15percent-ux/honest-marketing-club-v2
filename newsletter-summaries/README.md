# Newsletter Summaries（メルマガ自動要約アーカイブ）

購読中のメルマガを毎日自動でチェックし、要約してここに蓄積するためのフォルダ。
後から見直して、最終的に教材（コンテンツ商品）の素材として再編集することを目的とする。

## 対象メルマガ

| メルマガ | 差出人 | 配信時刻 | 格納先 |
|---|---|---|---|
| LINEスタンプ攻略メルマガ（発行者: ほこ） | info@news.aidotto.com | 毎朝 7:00 JST | `line-stamp-melmaga/` |

## 自動化の仕組み

1. 毎朝 7:30 JST に Claude Code のルーチン（スケジュールタスク）が起動
2. Gmail を `from:info@news.aidotto.com newer_than:1d` で検索
3. 新着メールがあれば本文を取得し、`_TEMPLATE.md` のフォーマットで要約を作成
4. `line-stamp-melmaga/YYYY-MM-DD_NNN_タイトル.md` として保存し、`INDEX.md` に追記
5. コミットしてリモートブランチへプッシュ（新着がない日は何もしない）

## ファイル命名規則

```
line-stamp-melmaga/2026-08-31_001_初回配信タイトル.md
                   └配信日────┘└号数┘└タイトル要約┘
```

- 号数（NNN）は 3 桁の連番。`INDEX.md` の最終番号 + 1
- `000` は登録確認メール（パイプラインの動作確認を兼ねる）
- 同じ Gmail メッセージ ID の要約が既に存在する場合は重複作成しない

## 教材化に向けて

各要約の「教材化メモ」欄に、将来どの章・テーマに使えそうかを書き溜めておく。
号数がある程度溜まったら `INDEX.md` のテーマ別マップを使って章立てに再構成する。
