## 01. 現在地

売っているのは「日本語教師」ではなく、**旅と両立できる生き方**。

**効いている資産**
- 旅を実際にしている（「稼げます」ではなく「稼ぎながら今ここにいる」が証明できる）
- 写真が撮れる（同業の日本語教師アカウントに対してビジュアルで即差がつく）
- 資格なし・英語不要（旅／ママ／副業の3層すべてに同じ言葉で刺さる）

**止まっている箇所**
- 入口はあるが受け皿がない → 見た人の連絡先が残らず、毎回ゼロから集客している
- いちばん強い話（娘さんとの留学）が閉じている → 公開したくない場所ではなく「登録者だけが読める場所」に置くべき資産
- 個別相談で話しすぎている → 時間の長さは価値提供ではなく、決断の遅延になっている

**3ターゲットは「1本の動線・3つの入口」**（商品も動線も同じ。リールの切り口だけ変える）

| 層 | 訴求 | 特徴 |
|---|---|---|
| ①旅好き | パソコン1台で、来月から旅先が仕事場になる | 最優先。拡散がいちばん伸びる |
| ②ママ | 熱を出しても、すみませんと言わなくていい仕事 | 共感が深く成約率が最も高い |
| ③副業・フリーランス | 合間の時間を、時給ではなくスキルに変える | 検討は長いが単価を落とさず売れる |

## 02. 結論：動線はこう組む

元資料の「インスタ → メルマガ → LP → 申し込み」から3点を変更しています。
**（1）受け皿を公式LINEにする （2）LPを2枚に分ける （3）メルマガを後ろにずらす**

1. **入口** — Instagram リール（週3本）。知らない人に届く唯一の場所。TikTok・YouTubeは当面、同じ素材の再利用先のみ（専用制作はしない）
2. **信頼** — プロフィール＋フィード＋ハイライト。フィードの世界観は残し、プロフ文とハイライト3本だけ「日本語教師の入口」として作り込む
3. **受け皿** — 公式LINE登録（＋メールアドレスも同時取得）。登録特典は「資格なしで日本語教師になる 7日間の地図」＝ステップ配信そのものを特典にするのが最短
4. **教育** — 7日間ステップ配信。**ここに娘さんとの留学の話を置く**（不特定多数には出さない／本気の人には必ず届く、が両立する唯一の場所）
5. **予約** — 個別相談LP（1枚目）。読了3分・1画面分。「誰向け／何が分かる／所要時間／枠数」だけ
6. **面談** — 個別相談 60分（事前アンケート必須）→ 05 の台本
7. **申込** — 本商品LP（2枚目）＋決済。相談後にだけ見せる。読ませるのではなく確認して押すページ

### 公式LINEは必要か → 必要。最優先で作るべき唯一のもの

メルマガ開封率10〜20%に対しLINEは60〜80%。スマホ中心の女性層ではこの差が動線の成否そのもの。
ただしLINEはアカウント停止リスクがあるため、**登録時にメールアドレスも同時取得**して資産を二重化する。
メルマガの「配信開始」は4ヶ月目から。アドレスの蓄積だけは初日から行う。

## 03. アカウント運用：旅アカウントは残す。ただし「集客はしない」と決める

- **旅アカウント** … 世界観と信用の置き場。数字を追わない・売らない。教師アカウントへの導線を1行だけ置き、月数回ストーリーズで触れる程度
- **日本語教師アカウント** … 集客の本線。ただし**フィードの写真は旅アカウントと同じ品質で撮る**（66万円のコンサルを含む同業に対して、いちばん模倣されにくい差）

| 面 | 目的 | 頻度 | 中身 |
|---|---|---|---|
| リール | 新規リーチ | 週3本 | 下の6つの型を回す |
| フィード | 信頼・世界観 | 週1〜2本 | 旅先の写真＋長めのキャプションで想いを書く |
| ストーリーズ | 関係構築・導線 | 毎日1〜3 | 日常／質問箱／LINE誘導（週2回まで） |
| ハイライト | 初訪問者の判断材料 | 3本固定 | ①自己紹介 ②受講生の変化 ③よくある質問 |

## 04. 制作オペレーション：リールの「自動化」

完全自動投稿は成果が落ちる。効くのは「毎日ゼロから考える」をやめる仕組み化。

### 回す6つの型

| 型 | 冒頭2秒の例 | 狙う層 |
|---|---|---|
| ① 数字の断言 | 「日本語教師の収入、正直に公開します」 | 副業・全般 |
| ② 誤解の訂正 | 「資格がいると思ってました？いりません」 | 全般（最も伸びる） |
| ③ 一日密着 | 「バンコクの朝6時、今日の授業は3コマ」 | 旅好き |
| ④ 変化の記録 | 「1年前、私はまだ会社にいました」 | ママ・副業 |
| ⑤ 質問回答 | 「”子どもがいてもできますか”に答えます」 | ママ |
| ⑥ 世界観 | 写真＋一言。保存とブランドのため | 全般 |

### 月1回のまとめ撮りに変える

1. **素材の日を月1日つくる** — 旅先で1日だけ撮影日にし、12本分（1本=3カット×15秒）を撮り切る
2. **台本はまとめて生成** — 6つの型×テーマをAIに渡し12本分を一度に。使うのは冒頭2秒と結びだけ、中身は自分の言葉に直す
3. **テンプレは3種に固定** — CapCutで「密着系」「テロップ主体」「写真スライド」。以後は素材差し替えのみ
4. **2週間分を予約投稿** — Meta Business Suiteで一括。投稿日にやるのはコメント返信だけ

> 自動化の定義＝「投稿を機械にやらせる」ではなく「**考える日を月2日に集約する**」こと。

### noteの役割

集客の主動線にしない。検索から来た人と、既に知っている人が深く知るための場所。月2本。想い・考え方・受講生の物語を書き、記事末に必ずLINEへの1行。
**娘さんとの留学の話はnoteではなくLINEステップ配信へ**（要望と戦略が一致する）。

## 05. 個別相談：「ここだけ話せばいい」の3つ

長くなる原因はほぼ1つ、**教えてしまっていること**。個別相談の価値はノウハウではなく「あなたの問題は何か」を言い当てることだけ。

1. **問題の再定義** — 「うまくいかないのは◯◯が足りないからではなく、◯◯だからです」
2. **順番だけ示す** — 「解決は A→B→C の順です」。何をやるかは言う、**どうやるかは言わない**
3. **案内** — 「それを一緒にやるのがこれです」。誰向け／期間／内容／価格／条件／期限を5分で

### 事前アンケート（これだけで15分短縮）

予約完了時にGoogleフォームを自動送信。**未回答なら相談を実施しない**と明記する。

1. 今のお仕事と、1週間に使える時間はどれくらいですか
2. 日本語教師に興味を持ったきっかけを教えてください
3. 半年後、どうなっていたいですか（できれば金額と生活で）
4. 今いちばんの障害は何だと思いますか
5. これまでに自己投資（講座・スクール等）の経験はありますか。差し支えなければ金額も

### 60分の台本

| 時間 | ブロック | 中身 |
|---|---|---|
| 0–3分 | 前提合わせ | ゴール・進め方・**最後に案内があること**を先に伝える。「今日は60分で、◯◯さんが今どこで止まっているのかをはっきりさせます。最後の10分で、もしお役に立てそうならご案内もさせてください。合わなければ遠慮なく言ってくださいね」 |
| 3–20分 | 現状ヒアリング（相手8割） | アンケートを深掘るだけ。書かれたことに「それはどうしてですか」を3回重ねる。沈黙を埋めない |
| 20–30分 | 理想を数字にする | 「いつまでに・いくら・どんな生活」を相手の口から出させる。**期限を言わせるまで次に進まない** |
| 30–38分 | ギャップの言語化（唯一の価値提供） | 相手が思っていた理由と**違う言葉で**言い切る。例：「足りないのは日本語の知識ではなく、”自分を選んでもらう理由”がまだ言葉になっていないことです」→ 最後に「という理解で合っていますか？」 |
| 38–45分 | 解決の全体像（3ステップだけ） | **各ステップのやり方は絶対に説明しない**。説明した瞬間に無料講座になり「自分でできそう」と感じて帰る。7分で終える |
| 45–55分 | 案内 | ①誰向け ②期間 ③やること ④サポート範囲 ⑤価格 ⑥条件・人数 ⑦返答期限。**価格を言ったあと自分から言葉を足さない**。「高いですよね…」は禁句 |
| 55–60分 | 質問と次のアクション | 「気になっている点は何ですか」→ 答える →「進めるとしたら、何が引っかかりますか」。**返事の期限と次に起きること**を決めて終わる |

### この60分で「話さないこと」

- 自分の経歴・実績の長話（3分以内。詳しく知りたい人はLINEステップで既に読んでいる）
- ノウハウの手順（「何を」までで止め、「どうやって」は言わない）
- 業界の一般論・市場の説明（ステップ配信で済ませる話）
- 他社・他講座との比較（聞かれない限りこちらから出さない）
- 価格の言い訳と値引きの示唆（半年66万円の相場がある市場。安さで勝ちにいかない）
- 聞かれていない質問への回答（沈黙をこちらが埋めない）

## 06. 数字：月3件成約からの逆算

| 段階 | 必要数/月 | 転換率の目安 | 下がったときのレバー |
|---|---:|---:|---|
| リールの総リーチ | 22,000 | — | 冒頭2秒の言葉／型②を増やす |
| プロフィール到達 | 660 | 3% | リール末尾の一言、コメント欄の固定 |
| LINE登録 | 100 | 15% | プロフィール文と登録特典の言葉 |
| 個別相談の予約 | 10 | 10% | ステップ配信6〜7通目、相談LPの見出し |
| 成約 | 3 | 30% | 05の台本、事前アンケートの徹底 |

リール1本2,000リーチなら月11本＝週3本でちょうど届く。**「週3本を切らさないこと」がこの動線で最重要の習慣**。
リーチが十分あるのにLINE登録が伸びない場合、増やすべきは投稿数ではなくプロフィール文。

## 07. 90日の組み立て（受け皿 → 集客 → 販売の順）

| 期間 | やること | ゴール |
|---|---|---|
| Day 1–30（基盤） | 公式LINE開設／7日間ステップ配信を書く／プロフ文とハイライト3本／事前アンケート作成／個別相談台本の完成／メールアドレス取得の設定 | 受け皿が完成し、明日から人を流せる状態 |
| Day 31–60（集客） | リール週3本／ストーリーズ毎日／まとめ撮り1日／個別相談LP（1枚目） | LINE登録50件／個別相談5件を実施 |
| Day 61–90（販売） | 個別相談の実施と台本改善／本商品LP（2枚目）と決済の整備／受講生の声を1件取る／note月2本を開始 | 個別相談10件／成約3件／次期の実績素材を確保 |

AMANE受講生向けコンテンツの改訂は **Day 90以降**。この90日で取れる「受講生の生の声」と「相談で実際に出た質問」が改訂の最良の材料になるため、先に作ると作り直しになる。

## 08. 次に決めていただきたいこと

1. **本商品の価格と期間** — 半年66万円という相場がある市場。同額に並べるか、期間を短くして単価を下げるか、逆に上げるか。ここが決まらないと個別相談台本の後半が書けません
2. **個別相談の枠数** — 週に何枠受けられるか。月10件なら週3枠が下限
3. **旅アカウントと教師アカウントの相互導線** — 旅アカウントで「日本語教師」をどこまで出してよいか
4. **公式LINEの登録特典** — 7日間ステップ配信そのものを特典にする案を推奨。別途PDFや動画を作る方向も可
