# 魚勝商店 小売戦略 2026

> すべての施策を「贈り物なら魚勝」というゴールにつなげる

## GOAL

**「高いけど、贈りたい。魚勝の商品なら間違いない。」**

## 戦略ファネル（3ステップ）

### ① 知ってもらう
新しいお客様との接点を増やす

- SNS
- Instagram / TikTok / TikTok LIVE
- ふるさと納税・クラファン
- 高級スーパー・百貨店

↓

### ② 信用・購入
魚勝の価値を理解して買ってもらう

- ホームページ・EC
- 魚勝レディー
- 信用販売
- 所属団体・地域活動・紹介

↓

### ③ ファン・贈答
繰り返し買い、誰かに贈ってもらう

- ファンクラブ
- 企業ギフト
- 春夏秋冬の商品提案
- お中元・お歳暮・周年・御礼

## 年間を通じて動かす共通テーマ

| 季節 | テーマ |
| --- | --- |
| 春 | 春ギフト |
| 夏 | どんちっちアジ |
| 秋 | 新物のどぐろ |
| 冬 | 高級のどぐろ・お歳暮 |

## 勝ち筋の方程式

**商品力 × 発信力 × 人とのつながり × 信用 → 「贈り物なら魚勝」**
