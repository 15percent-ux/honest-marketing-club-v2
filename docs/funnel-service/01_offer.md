## 1. ひとことで言うと

**「LP・公式LINE・予約管理」を、お店や教室ごとにまるごと作り、問い合わせから予約・リマインドまでを自動で回す仕組みにして納品するサービス。**

お客さまの流れ：
```
Instagram・広告・紹介
   ↓
公式LINEを友だち追加 ─→ 写真入りカード＋リッチメニュー
   ↓
トークの中で3問の診断 ─→ その人に合う提案（メニュー・コース・相談内容）
   ↓
トークの中、またはLPで日時を選んで予約
   ↓
確認メール／前日・1時間前のリマインド（メール・LINE）
   ↓
お店側：スマホの管理画面で予約一覧・状態・メモを管理
```

## 2. 誰に売るか

| 業種 | よくある今の状態 | 診断の例 | 診断の先にあるもの |
|---|---|---|---|
| 美容院・ヘアサロン | DMや電話で日程調整、ポータルサイト頼み | 髪の悩み・なりたい雰囲気 | おすすめメニュー→予約 |
| エステ・ネイル・リラク | 新規が単発で終わる | 肌・爪の悩み、通える頻度 | おすすめコース→初回予約 |
| 飲食店 | 予約は電話、コース予約が少ない | 人数・用途（記念日・接待） | コース提案→予約 |
| 講座・スクール・コーチ | 体験会への導線がない | 今の状態・目指したい姿 | タイプ診断→無料相談・体験会 |

共通する悩み：
- 問い合わせ・日程調整・リマインドに、毎日時間を取られている
- 公式LINEはあるが、URLを流すだけで「接客」になっていない
- 予約サイトやDMに頼っていて、自分のお客さまのリストが残らない
- LPを作っても、そこから予約までがつながっていない

## 3. 何を作るか（納品物）

| # | 納品物 | 中身 |
|---|---|---|
| 1 | 導線設計書 | ヒアリングをもとに「誰に・何を・どの順で」をまとめたもの。診断3問と結果の出し分けも設計 |
| 2 | 診断LP | 3問の診断 → 結果 → 説明 → チャット型予約フォーム（スマホ最適化・3種類の雰囲気から選択） |
| 3 | 公式LINEの接客 | リッチメニュー（デザイン込み）、友だち追加時の写真入りカード、トークの中で完結する診断と予約 |
| 4 | 予約の自動化 | 予約の自動記録、確認メール、前日・1時間前のリマインド（メール・LINE）、満席の枠の自動停止 |
| 5 | 管理画面 | スマホで予約一覧（今日／これから／過去）、状態（完了・キャンセル・無断欠席）、メモ、検索 |
| 6 | 計測 | Googleアナリティクス・Metaピクセル（任意）。どこで離脱しているかが分かる |
| 7 | 画像 | 共有されたときのサムネイル、リッチメニュー、カード画像 |
| 8 | 操作マニュアル | 管理画面とLINEの使い方（1枚もの） |

月額のツール費がかからない構成にする（予約データはお客さま自身のGoogleアカウントに保存）。
※ LINE公式アカウントの利用料（配信数による）と、独自ドメインを使う場合のドメイン代は実費。

## 6. 選ばれる理由（LPで伝えること）

1. **実際に触って確かめられる**：このサービスのLP自体が、この仕組みで動いている。デモで診断から予約まで体験できる
2. **LINEのトークの中で完結**：お客さまはページを行き来しない。カードとボタンだけで予約まで進む
3. **予約管理までセット**：作って終わりではなく、スマホで回せる管理画面つき
4. **月額のツール費がかからない構成**：データはお店のGoogleアカウントに残る
5. **煽らない設計**：偽のカウントダウンや根拠のない数字は使わない。お店の信用を守る導線

## 7. 売り方（この商品自体の販売ファネル）

```
Instagram・紹介・セミナー
  → 販売LP（診断3問：業種／今の予約の受け方／いちばんの悩み）
  → 診断結果「あなたのお店に合う始め方」
  → 無料相談の予約（チャット型フォーム）
  → 確認メール＋公式LINE連携
  → 無料相談（Zoom 45分）：今の導線を一緒に見て、プランと見積もりを提示
  → 申込・ヒアリングへ
```

無料相談でやること：
1. 今の集客〜予約の流れを一緒に書き出す
2. 手間がかかっている場所を特定する
3. 合うプランと、公開までのスケジュールを提示する
4. デモを一緒に触る

## 9. よくある質問（LP用の下書き）

- **Q. パソコンが苦手でも大丈夫？** → 管理画面はスマホで完結。使い方もお渡しします
- **Q. 公式LINEを持っていない** → 開設からお手伝いします
- **Q. 写真がない** → 撮影の段取り、またはイメージ画像の作成をご相談ください（イメージ画像には「イメージです」と表記します）
- **Q. 公開後に自分で文章を変えられる？** → サポート期間中はご依頼ください。期間後の変更は【要決定：保守プラン or 都度見積もり】
- **Q. 月額費用はかかる？** → この仕組み自体の月額ツール費はかからない構成です。LINE公式アカウントの利用料・ドメイン代は実費です
- **Q. 集客が増えることを保証してくれる？** → 成果の保証はしていません。予約までの手間を減らし、取りこぼしを防ぐ仕組みをつくります。伴走プランでは数字を見ながら一緒に改善します
- **Q. どんな業種でも使える？** → 予約や申込みがある業種（サロン・飲食・教室・講座・個人サービス）に向いています。合うかどうかは無料相談で判断します
