# Dipsy公式クリエイター応募LP 分解レビュー — 魚勝商店サイトへの転用設計図

対象: https://creator.dipsy.com/apply (2026-08-30時点のHTML/CSSを取得して解析)

目的: このLPの「プロっぽさ」を構成要素に分解し、魚勝商店の
ホームページを同水準のクオリティで作るための設計図として使う。

---

## 1. 技術構成(実測)

- Next.js (Turbopack ビルド) + Tailwind CSS 4系、Vercelにデプロイ
- 総HTML約430KB(サーバーレンダリング済み)。画像はwebp、動画はポスター画像つき
- ファーストビューの主要画像16枚を `<link rel="preload">` で先読み
- フォントは Google Fonts の Noto Sans JP (400/500/700) + Helvetica Neue

**魚勝商店への示唆**: 同じ構成(Next.js + Tailwind + Vercel/Netlify)で
十分再現可能。静的中心なら Astro でも可。凝った演出はCSSだけで
実現されており、重いJSライブラリは不要。

## 2. デザイントークン(CSSから抽出した実物の値)

```css
/* 色 — ほぼ無彩色 + 差し色1つ、という構成 */
--ink:   #0a0a0a;   /* テキスト・主役の黒 */
--paper: #fff;      /* 地の白 */
--mist:  #f9f9f9;   /* セクション差の薄グレー */
--line:  #e4e4e1;   /* 罫線 */
--sub:   #6b6b68;   /* 補助テキスト */
--ink2:  #444;
/* アクセント: #ec3b32 (赤)を極少量。蛍光緑 #26ff00 も一点だけ */

/* フォント — 見出しも本文も同じスタック。フォントで飾らない */
--disp / --label / --body:
  "Helvetica Neue", Helvetica, Arial, "Noto Sans JP", sans-serif;

/* モーション — イージングと時間をトークン化している */
--e-out:  cubic-bezier(.22,1,.36,1);   /* 減速系。出現アニメに */
--e-sym:  cubic-bezier(.65,0,.35,1);   /* 対称。ループ系に */
--t-fast: .3s;  --t-base: .55s;  --t-slow: .9s;

--header-h: 64px;
```

**ポイント**: 色数を絞る(黒・白・グレー3種・差し色1)ことが
「高級感」の最大の源泉。写真素材を主役にするため、UI側の色を消している。

## 3. タイポグラフィ

- 流体タイポグラフィを全面採用: `clamp(最小, vw係数, 最大)`
  - 巨大見出し: `clamp(80px, 10vw, 132px)` / `clamp(110px, 11vw, 170px)`
  - セクション見出し: `clamp(38px, 5.2vw, 64px)`
  - 本文: `clamp(17px, 2.05vw, 20px)`
- セクション見出しは英語大文字(VISION / SERVICE / FAQ / OPEN CALL)、
  本文・説明は日本語。この「英語ラベル+日本語本文」の対比が
  ブランドの空気を作っている
- h1はスクリーンリーダー用に隠し(`class="vh"`)、視覚上はロゴと
  マーキーで代替

## 4. ページ構造(セクション設計)

```
<header> 固定ナビ(64px、アンカーリンク)
<section id="top">      FV: フルスクリーンの画像マーキー
<section id="vision">   VISION: 理念コピー
<section id="terms">    SERVICE: 機能紹介 6項目(h3カード)
<section id="creators"> OFFICIAL CREATORS: 13名の実在者ショーケース
<section id="sponsoring"> SPONSORING: 協賛4件(実在の外部団体)
<section id="faq">      FAQ: 9問(不安の先回り)
<section id="form">     OPEN CALL: 応募フォーム
<footer>
```

- 各セクションは `id` つきでナビのアンカーと1:1対応
- 「理念 → 機能 → 実在の人・実績(社会的証明) → 不安解消 → 行動喚起」
  というLPの王道順序

## 5. ファーストビューの正体

`<img>` タグは1枚もない。CSSの背景画像を持つセル
(`mq-cell fim1-2` など)を3列(`mq-row`)並べ、無限マーキーで
流している。各列は複製を2セット並べてループ。動画セルはポスター
画像を先に見せる。

→ 「画像がリッチに動く印象」はCSSアニメーションだけで作れる、という好例。

## 6. モーション設計

キーフレーム16種が定義されているが、性格は3系統だけ:

1. **出現系** (`sec-en-skew-rise`, `badge-pop`, `cell-pop`, `lead-boing`)
   — スクロールで入った時に一度だけ。`--e-out` + `--t-base`
2. **環境系** (`drift`, `svcFloat`, `vd-float`, `crlBreath`)
   — 常時ゆっくり漂う。目立たない速度
3. **強調系** (`curPulse`, `spMkSwipe`, `fcta-spin`) — CTAやマーカーだけ

**ルール**: 動きは「入った時に1回」+「背景で微かに」+「CTAだけ主張」。
全部を動かさないことが上品さの条件。

## 7. なぜプロに見えるのか(結論)

| 要因 | 寄与 | 再現の難易度 |
|---|---|---|
| 実在の人物・作品写真の質と量 | 最大 | 素材次第(コード外) |
| 色を消したUI + 巨大タイポ | 大 | 低い(トークン通り作るだけ) |
| 流体clamp + 余白の一貫性 | 大 | 低い |
| 抑制されたモーション | 中 | 中(足し算しない自制が必要) |
| 実在の協賛・FAQによる信頼設計 | 中 | コンテンツ企画の問題 |

コード自体の難易度は高くない。**素材とコンテンツ企画が8割**。

## 8. 魚勝商店への転用プラン(叩き台)

「素材は沢山ある」前提での提案。

### セクション構成(Dipsyの型をそのまま転用)

```
FV        魚・仕込み・店頭の写真マーキー(縦3列)
VISION    店の理念(目利き・産地・歴史)を短い日本語コピーで
SHINSEN/仕事  こだわり6項目(仕入れ・目利き・締め・熟成・配達・相談)
PRODUCTS  看板商品 or 季節の魚ショーケース(Dipsyのクリエイター欄に相当)
TORIHIKI  取引先・実績(料亭・飲食店など = 社会的証明。Dipsyの協賛欄に相当)
FAQ       注文方法・配達エリア・最低ロット・支払いなど
CONTACT   問い合わせ/注文フォーム(= OPEN CALL に相当)
```

### トークンの置き換え案

- `--ink` は黒のまま。`--paper` を純白でなく生成り(#faf9f6程度)に
  すると食品らしい温度が出る
- 差し色は屋号や暖簾の色から1色だけ(朱・藍など)。使用箇所は
  マーカーとCTAのみ、Dipsyと同じ節度で
- 見出しの英語ラベルは、魚勝なら筆文字・明朝の日本語ラベルに
  置き換える選択肢もある(業態に合う方を選ぶ)

### 素材の要件(ここが品質の分かれ目)

- 横長・高解像度の写真を最低20枚(FVマーキー用に16枚 + 各セクション)
- 「人が写っている」写真を必ず混ぜる(店主・仕込みの手元)。
  Dipsyの説得力は人物写真から来ている
- 可能なら10秒程度の動画素材2〜3本(ポスター画像つきで軽く使う)

### 進め方

1. 素材の棚卸し(写真・文言・実績リスト)
2. このドキュメントのトークンでベースを実装(1〜2セッション)
3. 実素材を流し込み → 見た目の往復調整(ここに時間を使う)
4. Vercel/Netlifyへデプロイ
